# 경로 탐색 모드 (추가 사양)

fuzzy 검색과 별개로, 폴더를 한 단계씩 내려가며 경로를 만들어 복사하는 모드.

## 진입과 초기화
- Ctrl+L 은 현재 모드를 반전한다. 자동 판별은 하지 않는다.
- 입력창 왼쪽에 현재 모드를 표시한다.
- 기본 모드는 경로 모드다. 팝업 표시와 앱 기동 시 초기 모드는 마지막에 사용한 모드이고(`localStorage` 키 `fdpick.mode`, 모드가 바뀔 때마다 저장, 접근 불가여도 동작), 기록이 없으면(첫 실행) 경로 모드다. 입력창은 팝업을 열 때마다 비운다.

## 목록
- 입력이 비어 있으면 드라이브 목록을 보여준다(설정의 드라이브 유형 기준).
- 드라이브 문자만 입력하면(`d`, `d:`) 그 드라이브 루트의 폴더를 보여준다.
- 입력의 마지막 구분자 앞까지가 부모 폴더, 그 뒤 문자열이 이름 필터다.
  필터는 이름 접두사 일치로 거르고 fuzzy 점수 순으로 정렬한다.
- fd 를 쓰지 않고 폴더를 직접 읽는다(readdir). 폴더만, 숨김 폴더 포함.
- 제외 목록(Windows, Program Files 등)은 드라이브 루트 바로 아래에만 적용한다.
  AppData, node_modules, .git 은 직접 입력하면 들어갈 수 있다.
- 구분자는 `/` 와 `\` 를 모두 받는다.

## 키
| 키 | 동작 |
|---|---|
| Enter | 강조 항목의 경로를 복사. 강조 항목이 없으면 입력창의 현재 폴더를 복사 |
| `/`, `\` | 강조된 폴더 항목이 있으면 그 항목으로 완성하고 진입. 선택이 없거나(`c:` 직후, 끝 구분자 직후) 입력이 비었거나 강조 항목이 최근 항목이면(직접 고른 경우 제외) 구분자만 붙인다 |
| Tab | `/` 와 동일(완성 후 진입) |
| Up/Down | 강조 이동 |
| Shift+Tab | 경로 모드에서 상위 폴더로 |
| Ctrl+Enter | 탐색기에서 열기(Ctrl+O 와 같음). 폴더면 그 폴더, 파일이면 선택 상태로 |
| Ctrl+Space | 다중 선택 토글(두 모드 공통). 이전의 Tab 다중 선택은 폐지 |
| Ctrl+L | 모드 전환 |

- 복사 경로는 항상 `\` 로 정규화하고 끝 구분자는 제거한다(드라이브 루트 `C:\` 는 유지).

## fuzzy 모드의 Tab
- 강조된 검색 결과의 경로(파일이면 부모 폴더)로 경로 모드를 시작한다.
  입력창이 그 폴더 경로 + `\` 로 바뀌고 모드가 전환된다. 강조 결과가 없으면 무시한다.

## Shift+Tab (상위 폴더)
- 경로 모드: 입력이 가리키는 폴더의 한 단계 상위로 올라간다(`parentInput`).
  `D:\` -> `D:\`, `D:` -> `D:\`, `D:\`/`D:`/한 글자 드라이브 -> 빈 문자열(드라이브 목록). 입력이 비어 있으면 무시.
- 검색/최근 모드: 무시한다. 기본 포커스 이동은 항상 막는다.

## 최근 사용 모드
- Ctrl+L 은 fuzzy -> 경로 -> 최근 -> fuzzy 순으로 순환한다. 전환 시 입력을 비우고 즉시 질의한다.
  칩 텍스트는 `검색` / `경로` / `최근`.
- 최근 모드는 일회성이다. `fdpick.mode` 에는 fuzzy/path 만 저장하고 최근 모드에서는 저장값을 바꾸지 않는다
  (팝업을 다시 열면 저장된 fuzzy/path 로 시작).
- 최근 모드: 입력이 비면 최근 목록 전체(최신순), 입력이 있으면 퍼지 검색 결과. 모든 항목이 최근이므로 배지/구분선은 없다.
  상태줄은 `N개 일치`. 빈 목록 안내는 `최근 사용 기록이 없습니다`(입력 없음) / `일치하는 항목이 없습니다`(입력 있음).
- 경로 모드의 최근 구역: 입력이 있을 때만, 목록 맨 위에 최근 항목 최대 5개가 오고(`recent: true`) 그 뒤에 폴더 목록이 온다.
  최근 항목에는 `최근` 배지를 달고, 구역 마지막 항목 아래에 얇은 구분선을 둔다. 프런트는 순서를 바꾸지 않는다.
- 최근 항목에서 Tab, `/`, `\` 는 `folderOf(항목)` + `\`(파일이면 부모 폴더)로 진입한다.
  최근 모드의 Tab 도 같다. 폴더 목록 항목은 기존 동작.
- `missing: true`(경로가 더 이상 없음) 항목은 `.missing` 으로 흐리게(opacity 0.5) 표시하고 매치 강조는 유지한다.

## Enter 의 완성과 잘못된 경로 표시
- 입력 끝에 이름 일부를 치던 중(`C:\apps\b`)에 Enter 를 누르면 복사하지 않고 Tab 처럼 강조 항목(`bin`)으로 완성해 진입한다.
  한 번 더 Enter 를 누르면(이때는 초기 선택이 없으므로) 입력창의 폴더(`C:\apps\bin`)를 복사한다.
- 바로 복사하는 경우: 방향키/클릭으로 직접 고른 항목, 다중 선택이 있을 때, 입력한 이름이 강조 항목 이름과 이미 같을 때,
  강조 항목이 최근 항목일 때.
- 경로 모드의 기본 선택은 맨 위의 최근 항목을 건너뛰고 첫 폴더 항목이다(최근 항목은 방향키로 직접 고른다).
- 입력한 경로가 없으면(상위 폴더를 열 수 없거나, 이름과 일치하는 폴더가 하나도 없음) 입력 글자를 빨간색으로 표시한다.

## 사용자 액션
확장자별 프로그램/스크립트 실행, 선택 항목 일괄 전달. `config.toml` 의 `[[action]]` 항목으로 정의한다.

### 항목
| 키 | 의미 | 기본값 |
|---|---|---|
| `name` | 메뉴에 표시할 이름(필수) | - |
| `key` | 단축키(예: `Ctrl+Shift+V`). Ctrl 또는 Alt 가 반드시 있어야 하고, 내장 키와 충돌하거나 다른 액션과 같으면 비운다(경고) | 없음(메뉴로만 실행) |
| `ext` | 허용 확장자 목록(점 없이, 대소문자 무시). 디렉터리에는 확장자 조건이 있으면 적용되지 않는다 | 제한 없음 |
| `target` | `file`, `dir`, `any` | `any` |
| `run` | `[실행파일, 인자...]`(필수). 셸을 거치지 않는다. 실행파일 이름에는 치환이 없다 | - |
| `mode` | `each`(항목마다 1회) 또는 `batch`(선택 전체를 1회) | `each` |
| `cwd` | 작업 폴더(치환 가능) | 첫 대상의 폴더 |
| `window` | 콘솔 창을 보인다 | `false` |
| `close_popup` | 실행 후 팝업을 닫는다 | `true` |

### 치환
`{path}` 전체 경로, `{dir}` 부모 폴더, `{name}` 파일명, `{stem}` 확장자 뺀 이름, `{ext}` 확장자(점 없음),
`{paths}` 선택한 모든 경로. `{paths}` 는 인자 하나가 정확히 `"{paths}"` 일 때만 여러 인자로 확장된다(`--list={paths}` 는 확장되지 않는다).
`batch` 에서 `{path}` 류는 첫 경로 기준. 알 수 없는 `{foo}` 는 그대로 둔다.

### 호출
- Ctrl+K: 현재 대상(다중 선택이 있으면 그 목록, 없으면 커서 항목, 없고 경로 모드면 입력 경로)에 적용 가능한 액션 메뉴.
  Up/Down/PageUp/PageDown/Ctrl+P/Ctrl+N 이동, Enter 실행, Esc 메뉴 닫기(이전 목록 복원).
  적용 가능한 액션이 없으면 상태줄에 `적용할 수 있는 액션이 없습니다`.
- 단축키: `key` 가 있는 액션은 같은 대상 규칙으로 바로 실행된다.
- 실패하면 창을 유지하고 상태줄에 원인을 표시한다. 성공한 대상은 최근 사용 목록에 기록된다.
- 액션이 하나라도 있으면 도움말 끝에 `Ctrl+K 액션` 이 붙는다.

### 주의
- 셸을 쓰지 않으므로 `cmd.exe /c`, `powershell -Command` 를 직접 실행하는 액션에 `{path}` 를 넣으면 경로의 특수문자가 그 셸에서 해석된다(사용자 책임).
- `run[0]` 을 PATH 에서 찾는 일반 이름으로 쓰면 다른 폴더의 동명 실행 파일이 실행될 수 있다. 전체 경로 권장.
- `.bat`/`.cmd` 는 인자 인용 규칙이 달라 특수문자 경로에서 오동작할 수 있다(미검증).
- TOML 에서 백슬래시가 든 경로는 작은따옴표 리터럴 문자열(`'C:\Tools\x.exe'`)로 쓴다. 큰따옴표 안에서는 `\\` 로 써야 한다.

### 예시
```toml
# 선택한 이미지를 뷰어 하나로 한꺼번에 열기
[[action]]
name = "이미지 모아 보기"
key = "Ctrl+Shift+V"
ext = ["png", "jpg"]
target = "file"
mode = "batch"
run = ['C:\Tools\viewer.exe', "{paths}"]

# 폴더를 VS Code 로 열기
[[action]]
name = "VS Code 로 열기"
key = "Ctrl+Shift+C"
target = "dir"
run = ["code", "{path}"]
cwd = "{path}"
```
